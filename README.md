# BEATRIZ ABREU — Bia Nail Studio | Sistema de Agendamento

Sistema completo de agendamento online desenvolvido com **Next.js 15**, **TypeScript**, **Tailwind CSS** e **Supabase**.

## Como executar

```bash
npm install
cp .env.example .env.local
# Configure as chaves do Supabase
npm run dev
```

## Deploy

Conecte o repositório no Vercel. Adicione as variáveis de ambiente do Supabase no painel.
